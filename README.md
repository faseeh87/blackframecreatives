# Black Frame Creatives website

Static one-page site for Black Frame Creatives (marketing & photography, Mangalore), deployed on Vercel from `main`.

- `index.html` — the live page. `assets/` — logo, favicon, share image and portfolio photos (`assets/work/`).
- `_source/` — editable source (`src.html`) and `build.py`, which regenerates `index.html`. Not deployed.
- Enquiry form posts to FormSubmit, which emails ziaekbal@gmail.com. The first submission sends a one-time activation email.
